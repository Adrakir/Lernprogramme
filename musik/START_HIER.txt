DIREKTSTART IM BROWSER
Kurze Adresse (GitHub Pages):
https://adrakir.github.io/Lernprogramme/musik/

Die Kurzadresse leitet innerhalb desselben GitHub-Projekts zur bestehenden
Musikapp weiter:
https://adrakir.github.io/Lernprogramme/musik/Musik-Lernapp/

WICHTIG: Diese Adressen funktionieren, sobald GitHub Pages für das öffentliche
Repository „Adrakir/Lernprogramme“ aus dem Branch „main“ und Ordner „/ (root)“
veröffentlicht wird. Der öffentliche Betrieb wurde nicht unabhängig bestätigt.
Die Website benötigt kein ChatGPT-Konto.

WENN DIE ADRESSE NICHT FUNKTIONIERT
1. GitHub öffnen: https://github.com/Adrakir/Lernprogramme/settings/pages
2. Unter „Build and deployment“ die Quelle „Deploy from a branch“ auswählen.
3. Branch „main“ und Ordner „/ (root)“ auswählen und speichern.
4. GitHub Pages nach dem Aufbau erneut über die kurze Adresse öffnen.

DIE BESTEHENDE APP
Die Musikapp bleibt unverändert im Projektordner „Musik-Lernapp“.
Sie enthält den geführten Lernweg, Noten und Pausen, Taktarten, Hörübungen,
Rhythmuswörter, das Taktlabor, Musikspiele, Unterrichtsbereich und PDF-Hefte.

AUF HANDY UND TABLET
Die GitHub-Pages-Adresse direkt im Safari-, Chrome- oder Edge-Browser öffnen.
Die Nutzung ist ohne ChatGPT-Login vorgesehen. Auf dem Homescreen kann ein
Lesezeichen zur App angelegt werden.

OHNE INTERNET
Unter „Sicherung und Offline-Lernen“ kann die Musikapp nach dem ersten
Online-Start für Offline-Nutzung gespeichert werden. PDF-Hefte lassen sich
zusätzlich herunterladen. Die Offline-Nutzung ist im Browser geräteabhängig.

LERNSTAND
Lernstände werden auf dem jeweiligen Gerät gespeichert und nicht automatisch
zwischen Domains oder Geräten übertragen. Sichere alte Ergebnisse vor einem
Wechsel von der bisherigen Website als JSON-Datei und importiere sie bei
Bedarf unter „Sicherung und Offline-Lernen“ auf der neuen Website.
