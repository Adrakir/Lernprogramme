# Farbatelier · Klasse 5

Interaktive Lernwerkstatt zu Johannes Ittens zwölfteiligem Farbkreis. Öffne die [Lernapp](https://adrakir.github.io/Lernprogramme/farbatelier/). Das [Lernheft als PDF](lernheft.pdf) gehört zur App.

Farbkreis, Mischlabor, Malaufträge und Wissenscheck laufen im Browser. Die persönlichen Eingaben bleiben im jeweiligen Browser. Für gemeinsam genutzte Geräte gibt es einen Gastdurchgang. Zum lokalen Testen diesen Ordner mit einem statischen Webserver öffnen.
